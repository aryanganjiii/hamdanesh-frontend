# فرانت‌اند هم‌دانش

رابط کاربری هم‌دانش با React و Vite ساخته شده است. رابط فارسی و راست‌چین است و صفحه‌های گفت‌وگو، تاریخچهٔ محلی چت، نمایش منابع و مدیریت اسناد را ارائه می‌دهد.

## پیش‌نیازها

- Node.js نسخهٔ 22.12 یا جدیدتر
- سرویس بک‌اند هم‌دانش در حال اجرا روی `http://127.0.0.1:8000`

## اجرا

```powershell
npm install
npm run dev
```

نشانی توسعه به‌طور پیش‌فرض `http://127.0.0.1:5173` است. Vite درخواست‌های `/api` را به بک‌اند محلی هدایت می‌کند؛ بنابراین ابتدا بک‌اند را اجرا کنید. کلید AvalAI فقط در تنظیمات بک‌اند قرار می‌گیرد و در مرورگر استفاده نمی‌شود.

برای ساخت نسخهٔ تولیدی:

```powershell
npm run build
```

## ساختار

- `src/api`: کلاینت ارتباط با API
- `src/hooks`: state و منطق مشترک رابط
- `src/components/chat`: صفحه و اجزای گفت‌وگو
- `src/components/documents`: صفحه و اجزای مدیریت اسناد
- `src/components/layout`: پوسته و نوارهای رابط
- `src/components/common`: اجزای عمومی
